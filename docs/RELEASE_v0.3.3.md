# 对白 v0.3.3

本版发布独立接手后的稳定性修复；正式界面继续使用现有工作台。

- 内置六种大陆普通话音色，启动不联网获取音色目录；默认根据明确称呼匹配客户声音，逐通手动选择优先。
- 时间固定毫秒，同起点客服在前；去掉 A/B 交换，按 XML 角色配对和显示。
- 批量生成必须有效结果目录；真实保存回执才标记已保存，保存失败可独立重试。
- 保留上一份结果入口，完善关窗、退出和未保存音频保护。
- 修复 Mac 中文 ZIP 路径、符号链接、退出交接与下载来源标记；Gitee 优先并校验同版本 GitHub 备用文件。
- 建立分层协作规则、可复现环境及 React 准备工程；完整界面改版和数字文件命名留待 v0.4.0。

## 安装与验证边界

Mac 已安装 v0.3.x 的用户需下载新版 ZIP，正常退出旧版后手动替换一次应用；之后再使用修复后的自动更新。保留系统安全确认，不关闭 Gatekeeper 或删除隔离标记。

Windows 构建、联网合成和原生窗口由 CI 验证。隔离更新可能停在系统安全确认；CI 包装门槛通过不等于真实国内 Windows 设备或完整更新链路通过。

两平台完整源码及许可随安装 ZIP 提供；下载后可核对各自 .sha256 或 SHA256SUMS。在线合成仍依赖微软服务，本版不保证所有网络均可达。
