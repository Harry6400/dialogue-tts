# 对白 v0.4.1

- 全工作台更新蓝灰浅色与深色主题，统一列表、声音设置、菜单和弹窗；保留对白名称与标识。
- 修复扫描顶部进度条静止：显示真实阶段与文件计数，未知总数时不显示百分比；减少动画设置下保留静态反馈。
- 生成、暂停、继续与重试移到中央顶栏，不再占据底部独立区域。取消底部预览，点击编号直接进入完整核对；窄窗口支持切换通话和跨页前后核对。
- 分页增加首尾跳转、页码直达和当前范围显示，六万通无需逐页翻找；列表仍按每页最多 100 条读取。
- 批量声音操作靠近选择区，当前通话清楚显示实际音色；修复鼠标套框、搜索双重焦点、标签悬停及窄窗口空结果恢复。

保留已有批次、恢复、数字命名、同名不覆盖和真实保存回执契约。错误分类收紧和重复排序说明压缩属于后续建议，不包含在本版。

## 安装与验证边界

Mac 为 Apple Silicon 版本，使用临时签名，未经 Apple 公证；Windows 为 x64 版本，可能显示未知发布者提示，请按系统正常流程处理。v0.3.3 起可使用修复后的自动更新，v0.3.2 及更早版本需先手动安装新版。

点击生成、继续或重试合成会将相应文本发送给微软语音服务；启动、扫描和恢复目录不会自动合成。使用者需确认正文已脱敏。本版不克隆原声，不修改原始 XML。

Windows 的构建与原生检查来自托管 CI，不等于所有国内设备与网络已通过验收；macOS 12／Safari 15 和 Edge 109 真机兼容性仍以实际环境为准。完整源码、锁定依赖和许可随安装 ZIP 提供，摘要见各自 `.sha256` 与 `SHA256SUMS`。
