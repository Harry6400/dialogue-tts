# 大目录与持久任务

## 权限与存储

原生壳通过系统面板授予输入、输出目录，再用独立 `X-Native-Token` 通道委托可信本机服务访问。该令牌不进入页面配置或合成 worker 环境。普通 `X-App-Token` 不能注册路径。浏览器只持有不透明目录 ID；显示路径不是授权。

原生模式在应用私有状态目录存储 SQLite 文件，验证候选使用既有隔离验证根。目录授权持久保存但重启后不自动激活，恢复需重新核对目录身份。输入不递归，拒绝链接和特殊文件，每文件仍最多 2 MiB；文件级失败进入问题列表，不截断整个目录。

`workspaces/index.sqlite3` 保存散列身份、文件名、源文件摘要、声音、选择和任务状态，不保存 XML 正文。正文仅在受限解析、核对或当前合成时读取；生成前重新比较输入摘要。索引支持按目录全局配对与输出重名检查。文件配对查询使用覆盖索引，避免在大目录反复全扫描。

`native-workspace.sqlite3` 保存原生授权、保存意图和可信完成回执。完成记录按目录、文件名与指纹索引，不淘汰早期回执；核验实际文件大小与 SHA-256 才能跳过。旧 JSON 回执迁移后仍需实际文件核验，迁移不移动或删除 MP3。

一次目录选择只提交目录能力，不把全部 XML 正文返回页面。后台完成全目录配对、重复声道和目标重名检查后，才允许生成。当前只允许一个目录扫描；同一授权目录重复导入会复用正在扫描的工作区，其他目录需等待或取消。分页摘要和单通详情分开查询，不按文件枚举顺序切断一对 XML。

## 页面接口

页面发起的修改仍要求页面令牌和严格的本机 Host、Origin；原生私有接口单独验证原生令牌。大目录接口请求体受 256 KiB 限制。

| 接口 | 用途 |
|---|---|
| `GET /api/workspaces` | 读取最近 100 个工作区摘要，包含已结束记录；不自动扫描或联网 |
| `GET /api/workspaces/safety` | 读取全部工作区的安全状态；优先于工作区 ID 路由匹配 |
| `POST /api/workspaces/import` | 用输入目录 ID 创建后台扫描 |
| `GET /api/workspaces/{id}` | 编号搜索、状态筛选、排序、分页；最多返回 100 条摘要 |
| `GET /api/workspaces/{id}/next-issue` | 在当前搜索和异常分类下定位下一问题，返回单项 ID 和实际页码，可循环；不返回完整 ID 数组 |
| `GET /api/workspaces/{id}/snapshot` | 按 revision 返回总体统计和有限变化项 |
| `GET /api/workspaces/{id}/items/{item}` | 按需核对正文、真实源文件和声音来源 |
| `POST /api/workspaces/{id}/selection` | 当前页、全筛选、增量勾选与清空，返回选择快照 ID |
| `POST /api/workspaces/{id}/settings` | 整体设置、逐通或所选通话的客户音色覆盖 |
| `POST /api/workspaces/{id}/folders` | 在停止状态重新绑定已获原生授权的目录 |
| `POST /api/workspaces/{id}/start` | 明确授权后，冻结选择、声音与输出目录 |
| `POST /api/workspaces/{id}/pause` | 当前通话完成后暂停派发 |
| `POST /api/workspaces/{id}/resume` | 继续生成需重新明确授权；恢复扫描或设置重算属于离线操作 |
| `POST /api/workspaces/{id}/retry` | 分别重试合成失败或完整缓存的保存失败 |
| `POST /api/workspaces/{id}/cancel-scan` | 停止当前扫描、设置重算或输出核验；不发送文本 |
| `POST /api/workspaces/{id}/finish` | 结束前按缓存事实重新核对；有受保护音频时，必须先保存或显式提交 `discard_unsaved:true` 才能清理；保留输出和完成账本 |
| `GET /api/workspaces/{id}/items/{item}/audio` | 经授权与文件核验的真实音频，支持 Range |

新原生方法为 `choose_workspace_input`、`choose_workspace_output`、`restore_workspace_access(workspace_id)`。旧目录桥继续服务旧页面回归，新工作台不调用一次返回全部 XML 正文的旧导入接口。

异常分类由实际 `error_code` 和错误状态在本机 SQL 中汇总为声道配对、无效输入、输入变化、目标冲突、合成失败、保存失败与其他。`issues` 是整批计数，`save_pending` 单独显示，不把目录或空间阶段伪装成条目原因。`issue` 白名单贯穿分页和选择；`selection_query` 仅记录末次选择操作条件，恢复后仍以持久成员为准，不重放查询。`ready_selected` 表示已选成员中当前可生成的数量。

分页中的 `total` 是整个工作区条目数，`matched_total` 是当前筛选结果数。`selection_id` 引用服务端保存的选择范围；生成请求不包含数万个条目 ID。快照最多返回 100 个变化条目，`reset:true` 表示调用端需要重新读取当前页。无效 XML、缺轨等条目仍可读取真实来源和错误说明，不能为它们编造正文或角色。

单通预览的 `voice_choice.evidence_row_id` 是可选字段。只有称呼匹配成功时，才使用同一匹配规则定位可见客服段落；引用、歧义和静音内容不能作为该字段的依据。

## 整批 CSV 清单

`POST /api/workspaces/{id}/report {}` 固定导出整个批次，与当前搜索、状态筛选和勾选范围无关。扫描及全局配对尚未完成时不可导出；生成期间可按创建时的 SQLite 只读事务生成一致快照，不暂停或修改任务。服务逐行写入私有临时 CSV，不把全部记录、正文或文件路径传给页面。

清单包含批次及内部记录编号、输出编号、每份 XML 的源文件名和角色、结果文件名、处理状态、异常代码和原因；重复来源也逐份列出。没有 XML 正文、静音原文或完整私人路径。文件使用 UTF-8 BOM、带引号单元格与 CRLF；有公式风险的文本、长数字或带前导零编号添加可见的 `文本：` 前缀，防止表格软件执行或改写。

创建只返回不透明 `report_id`、文件名、行数、索引 revision、大小与 SHA-256。原生 `save_workspace_report(report_id)` 打开独立 CSV 保存面板；只有独立原生令牌接口接受系统选择的目标。它不修改 MP3 目录授权或音频回执，同名文件不覆盖。

保存成功需核对真实 CSV 回执；取消与失败分别反馈，失败保留同一快照供重试。`POST /api/reports/{id}/discard {}` 只删除该临时清单。刷新丢失标识或达到最多四份临时快照限制时，可显式调用 `POST /api/reports/cancel-pending {}` 取消本服务会话尚未保存的临时 CSV；不会删除批次、音频或已经保存的清单。创建、读取或保存中的清单阻挡这类清理，也纳入退出及更新的忙碌状态；闲置 CSV 快照不冒充未保存音频。字节限制触发明确错误，不能静默截断导出。

## 执行与恢复

后台持有有界串行队列。页面关闭、刷新或轮询失败不会负责派发下一项。每通完整音频先进入持久缓存，再由可信目录适配器原子无覆盖保存；保存回执与文件一致后才释放缓存。目录不可用、预检空间不足或保存失败会暂停派发。

正常保存使用 `saving` 状态；实际保存失败或缓存校验不一致使用 `save_error`，重启后的完整待保存结果使用 `save_pending`。工作区 worker 的源绑定到持久记录；复制到缓存前核对实际长度、摘要和 MP3，刷盘发布后释放已结束 worker 的重复源。转存失败保留完整源，恢复保存不重合成。规范化正文辅助文件在不再需要后清理；旧手动／Batches worker 和试听仍使用本会话临时存储。空间检查计入 worker 资源，默认缓存预算为 512 MiB。

暂停在通话之间发生。个别输入或合成错误继续其他项；连续三通合成失败暂停。重试保存不要求联网授权且不调用合成，只需要有效输出目录和完整缓存；缓存缺失不会暗中合成。重试失败合成仍需明确授权，且不顺便执行原待生成项。

恢复时重新核验目录及已保存文件。显式继续或重试任务时，完整缓存优先保存；没有完整音频的中断通话重新生成，不能称为段落断点续传。输入变化进入独立问题状态。更换输出目录后，已保存项仍定位原目录，未完成项使用新目录。

启动不自动继续合成。已保存条目先变为 `unverified`；显式恢复目录访问后，后台核验实际输出。来源目录未恢复时，声音设置不能触发重算，也不能把原本合格的条目改成输入变化错误。未结束计划中的选择和声音快照保持冻结。

原先完成的计划在全部实际输出核验成功后恢复完成状态，后来勾选的新通话仍可直接开始新一轮，声音设置也恢复可编辑。核验期间以内部持久标记保留原状态，取消或再次崩溃不把已完成计划误当作仍待继续；实际缺失、冲突或中断则继续按原规则处理。

| 离线操作中断 | 持久状态与继续方式 |
|---|---|
| 初次扫描意外中断 | `interrupted / recovery_scan`；`resume` 在原工作区重新扫描，不自动加入未核验成员。主动取消初次扫描则为 `cancelled`，需要重新导入。 |
| 设置重算取消或退出 | `interrupted / recovery_settings`；禁止生成和继续编辑，`resume` 离线重新计算合格条目的元数据。 |
| 输出核验取消或退出 | `interrupted / recovery_checking`；保留已经核验的条目，再次恢复目录访问只核验剩余 `unverified`。 |
| 合成或保存阶段中断 | `interrupted`；先恢复授权并核对结果，显式继续生成或仅重试保存。完整缓存不能因条目原先仍是 `running` 或 `queued` 而被忽略。 |

取消在当前文件检查或当前受限解析结束后生效。每次后台操作持有独立取消事件，停止输出核验不会发送文本；未完成的设置重算不能报告为已就绪。

## 完整缓存与全局安全状态

完整缓存通过 `.tmp` 原子更名为 `.mp3` 后，才写入保存中状态。启动、摘要、安全检查和结束操作都会重新对账，覆盖更名成功但数据库尚未提交的崩溃窗口。对账根据缓存名中的工作区与条目 ID、数据库中的目标名和指纹绑定结果，并通过同一受限文件描述符检查 MP3 格式、大小和 SHA-256；单文件上限为 256 MiB，新检查受缓存预算约束。

有效完整结果恢复为 `save_pending`，重试保存不会重新合成。`.tmp` 不视为完整结果。无法关联、超出核验预算、不可读取或校验不一致的 `.mp3` 保留并继续受到保护，不能当作可静默清理的数据。只有核实原生保存回执，或用户明确放弃该工作区未保存结果后，才能删除完整缓存。

摘要中的 `has_unsaved_audio`、`unsaved_audio_count` 依据当前工作区缓存事实；`global_unsaved_audio` 表示全部工作区的受保护缓存。它们不能仅由 `save_error` 等数据库状态推导。

`GET /api/workspaces/safety` 与原生私有 `POST /api/native/workspaces/safety {}` 返回全局布尔字段 `busy`、`unsaved`、`saving`、`pending`。正常后台检查的 `pending` 为 `false`；读取异常、字段缺失或类型不符属于未知状态，按阻挡处理。原生私有接口仍要求独立原生令牌，页面令牌不能代替。

退出与更新同时合并全局工作区状态、页面上的手动保存或试听状态。切换到闲置工作区不能隐藏其他工作区的扫描、派发、保存或未保存缓存。保存和状态未知时不放行；可以持久恢复的任务中断与旧页面临时结果的放弃确认分别处理。

## 容量验证

运行 `python tools/verify_large_workspace.py --calls 60000 --output verification/large-workspace.json`，会在私有临时目录创建 12 万份虚构 XML，执行扫描、选择持久化和六万次替代合成、真实保存及回执核验。替代音频使用本项目静音样本，不访问在线语音服务；它验证容量和调度，不证明真实在线吞吐或长期服务稳定性。临时输入、输出及状态在结束后清理。

`tools/verify_workspace_crashes.py` 使用隔离子进程和 `os._exit` 检查部分缓存、完整缓存发布、目标输出发布、回执提交等边界。该检查不同于单元测试中的状态或异常注入，也不代表断电、真实在线合成、原生应用退出与更新的双平台验收。具体执行结果记录在验证资料中，不由本架构文档代替。
