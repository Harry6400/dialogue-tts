## 本轮实现

- 工作区、仓库与四个模块共六层 AGENTS；PRODUCT、架构、接口、开发和本机索引说明。
- Python 3.12 项目虚拟环境与 uv 哈希锁；Node 22/npm workspace、统一 npm 锁、npm ci；统一入口 tools/check.py，Mac/Windows 离线 CI。
- React 严格类型、CSS Modules、共享语义变量、HTTP/原生适配、取消/失败/不支持/未知结果、幂等回调清理、类型/Lint/Vitest/构建。显式 Safari 15/Edge 109 目标，正式入口未切换。
- 六种内置大陆普通话，启动不访问音色服务或缓存；旧非普通话偏好需用户明确重选。默认称呼匹配、逐通覆盖和实际声音显示。
- 固定毫秒，显式秒单位报错；同起点客服在前，去掉 A/B 交换，按角色显示与配色。
- 批量必须有效原生输出目录，通过可写性与空间检查后才提交；逐通回执确认保存，独立重试保存；单通保留手动保存。
- 修改设置、重新预览和错误时保留上一份结果，标明旧设置；未保存台账不依赖结果区是否可见；结果区共同滚动，避免相互压缩遮挡。
- Mac 关窗/Cmd+Q/菜单/页面退出共用保护；Windows 退出查询移到异步审核线程，避免 UI 回调死锁。
- Mac Unicode ZIP、内部链接和执行权限正确保留；构建后自动用生产解包器检查实际包与签名身份。源码包包含工作流引用的全部测试、前端源码和锁，排除依赖与私人资料。
- Gitee 优先，网络错误与验证错误分别处理；GitHub 备用按已选 tag 获取同版本并核对相同文件、大小和摘要。
- Mac 下载来源标记使用系统 xattr 工具写入并读回；真正待安装的同文件系统副本在移动旧安装前重新核验标记，不删除隔离属性。
