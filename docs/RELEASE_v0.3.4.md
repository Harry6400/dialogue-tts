# 对白 v0.3.4

沿用现有工作台及浅色、深色模式，完成固定数字文件名、保存和 Mac 退出修复。

- 先按 XML 通话标识及 AGENT/USER 配对，再校验两个文件的数字前缀相同、末位分别为 0 和 1。例：202610270080.xml ＋ 202610270081.xml → 20261027008.mp3。保留前导零，扩展名大小写均可；异常名和同批重复目标名标错跳过，其他通话继续。
- 预览、单通／批量任务、下载、原生保存和 ZIP 内 MP3 使用同一固定名称。旧通用名称文件不自动重命名。
- 已有文件仅在可信保存记录、音频指纹、名称、大小和摘要全部匹配时跳过；其他同名冲突不覆盖、不自动编号。单通手动保存只选择文件夹，不改变批量默认目录。
- 保存失败保留已生成音频，处理冲突后可重试保存，无需重新合成；页面显示具体冲突原因。
- 修复 Mac 页内退出后窗口进程残留，以及同类程序发起的退出调度；保留任务、保存和未保存结果保护。

## 安装与验证边界

Mac v0.3.2 及更早版本需手动安装包含更新器修复的新版本；v0.3.3 起可使用修复后的自动更新。Mac 包为临时签名，未经 Apple 公证；Windows 可能显示未知发布者提示，按系统正常流程处理。

Windows 完整更新的无人值守验收可能停在系统安全确认。构建、联网合成、原生窗口和包装门槛通过不代表系统确认后的端到端更新通过；国内 Windows 真机及旧系统真机兼容性仍未验收。

语音合成需要联网并明确允许发送已脱敏文本，不克隆原声。完整源码与许可随两个安装 ZIP 提供，摘要见各自 .sha256 和 SHA256SUMS。v0.4.0 的界面大改不包含在本版。
