# 对白 v0.4.0

- 新增 React 批次工作台：批次切换、分页列表、正文核对和声音设置共用状态；支持浅色、深色外观。
- 大目录在本机流式扫描、全局配对并保存 SQLite 索引。页面每次最多读取 100 条摘要，支持跨页选择和筛选，原始 XML 不改写。
- 生成可暂停，重开后恢复目录与核验结果，再主动继续。完整未保存音频优先重试保存，不重新合成；真实保存回执才标记已保存。
- 增加异常分类、跨页问题定位及整批 CSV 清单导出。清单包含来源文件名、输出名、状态与异常，不包含正文或完整路径。
- 精简操作区：点击生成直接执行，去掉额外授权勾选；选择操作改为图标，减少重复说明并放宽布局间距。版本信息与 Mac 菜单检查更新入口更清楚。
- 保留数字文件命名、同名不覆盖、退出与更新保护。结束任务保留已保存 MP3，不会自动重命名旧输出。

## 安装与验证边界

Mac v0.3.3 起可使用修复后的自动更新；v0.3.2 及更早版本需先手动安装新版。Mac 包为临时签名，未经 Apple 公证；Windows 可能显示未知发布者提示，按系统正常流程处理。

六万通容量与崩溃恢复采用虚构 XML 和替代音频验证，不代表微软在线合成吞吐。Windows 系统确认后的完整更新、国内 Windows 真机、macOS 12／Safari 15 与 Edge 109 真机仍未全部验收；最新构建证据见项目状态。

点击生成会将相应文本发送给微软语音服务，仍需联网并由使用者确认正文已脱敏。不克隆原声。完整源码、锁定依赖及运行许可随两个安装 ZIP 提供；摘要见各自 `.sha256` 和 `SHA256SUMS`。
