# 共享服务与现有页面

- 继承仓库规则；HTTP、解析、合成、任务和页面是不同职责，不让界面代替后端验证。
- 只接受既定 XML 结构，固定毫秒；同起点 AGENT 在 USER 前，同角色保持原段顺序。静音和通话元数据的隐私边界不能削弱。
- 普通话目录是版本内置数据；所有选择、试听、逐通覆盖和后端校验使用相同范围，不在启动时查询在线目录。
- 手动逐通覆盖只影响该通话。全局默认与最终生效声音分别表示，不用界面默认值冒充自动匹配结果。
- 批量生成前检查真实原生结果目录；后端不接收前端提供的任意文件路径。
- 任务、输出、保存分别跟踪。改变设置或解析失败不丢弃已有下载入口；失败重试不重复合成已生成音频。
- 目录来源不能用来推断是否联网。常规测试用可注入目录、虚构数据及临时存储，不写用户缓存。
- 保持 Host、Origin、令牌、资源路由和输入上限；不要为开发预览放宽正式服务限制。
- 改接口时同步类型、调用端、原生契约和行为回归；不要靠删除断言使测试通过。
