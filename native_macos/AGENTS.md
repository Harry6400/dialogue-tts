# Mac 原生层

- 继承仓库规则。遵循 AppKit/WKWebView 的线程和生命周期要求，界面操作在主线程执行。
- 前端回调只接受主框架的精确本机来源。系统路径、下载目标、更新参数只能由原生授权或可信进程参数产生。
- 目录能力与保存回执必须验证实际文件；取消系统面板不得改写已有选择或表示成功。
- 正常关窗、Cmd+Q、退出菜单使用同一套保护。更新退出保持单独的事务规则，不能强制杀进程安装。
- 保存操作未完成或前端状态未知时不静默退出；未保存结果允许返回保存、取消或明确放弃。
- 测试通过可注入存储和专用候选隔离真实偏好及安装；不得把测试入口变成前端任意路径权限。
- 分发后验证真实 ZIP、文件权限、符号链接、架构、包身份和签名；不能关闭 Gatekeeper 或删除隔离属性来通过测试。
