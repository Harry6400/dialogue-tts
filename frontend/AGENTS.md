# React 开发准备工程

- 继承仓库规则。当前是否为正式入口以项目状态和实际资源服务为准，不凭开发服务器可用就宣称已接入。
- 使用 React、严格 TypeScript、CSS Modules 与共享语义变量。暂不引入路由、全局状态库或大型组件库。
- 围绕已确认的列表＋详情、多通批量流程组织功能；保留对白的中文、克制和绿色身份，不加入营销首屏。
- HTTP 与原生能力经 services 层访问；组件不直接拼接系统路径、更新 URL 或命令。
- 回调注册与清理幂等；重复挂载不重复提交任务。区分取消、失败、不支持和状态未知，测试桥只在测试中启用。
- 运行类型、Lint、单元测试、生产构建及 React Doctor；保留键盘焦点、中文可读性和减少动画。
- 显式支持 Safari 15、Edge 109 的构建目标，核对 CSS/API。编译目标不能代替对应系统真机验收。
- 不把旧页面整段脚本塞入 React。正式入口切换时同步 HTTP、资源打包和双平台 WebView 检查。
