对白 · Windows x64

1. 解压后双击 DialogueTTS.exe。应用会打开自己的独立窗口，不会打开默认浏览器。
2. 选择同一通话的两份 XML，或多选多通话 XML；预览后生成 MP3。
3. 批量生成前选择有效结果文件夹；每通生成后自动保存，失败可重试保存。单通保留手动保存。确认文本已脱敏后再允许合成。
4. 退出会检查运行任务、保存操作和未保存音频；按提示返回保存、明确放弃或取消退出。

不需要安装 Python、FFmpeg 或部署服务器。需要联网访问微软语音服务。
界面使用 Windows 系统 WebView2，未捆绑大型 Chromium。若系统缺少 WebView2，应用会提示微软官方安装页面，由你确认安装；应用不会自动下载或安装系统组件。
解析在本机完成；只有点击合成后，所选文本才会发送给微软。原 XML 不会被改写。
输出先保存在临时目录；退出会清理，因此请先下载要保留的音频。

“检查更新”优先查询本项目 Gitee 分发源，网络故障可回退 GitHub 的相同版本、相同文件。确认后校验、安装并重启；系统安全确认仍需正常处理，不能把启动状态未知当作成功。

这是个人项目的未签名应用。Windows 可能提示发行者未知；本说明不要求关闭 Defender、SmartScreen 或任何安全设置。若被系统阻止，请先核对下载来源和 SHA-256，不要忽略安全警告。

语音服务可能限流或改变，不保证永久免费、无限用量或可用于任意商业用途。
段间停顿以 MP3 帧为单位，量化误差不超过约 12 毫秒，不会自动对齐旧录音时间戳。
