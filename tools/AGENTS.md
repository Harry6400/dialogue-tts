# 构建与检查工具

- 继承仓库规则。工具从自身位置定位仓库，不依赖开发者绝对路径或全局私人配置。
- 锁定安装依赖；常规检查与真实联网合成、原生验收分开报告。统一入口应返回可靠的退出码。
- 构建不替换用户安装、不发布、不重写历史 Release。产物与缓存使用隔离目录，保留必要候选和轻量证据。
- Mac ZIP 使用可被生产更新器读取的 Unicode 路径、权限和内部相对链接；用真实产物回归，不放宽安全解包规则。
- 源码导出包含实际构建、工作流和测试所需的文件、前端源码及锁文件；排除依赖、缓存、私密配置和证据目录。
- 第三方许可、来源和可重建资料必须随包保留。Node 仅供开发构建，最终用户不需要安装 Node 或 Python。
- Windows CI 的系统确认或真实设备缺口必须显式记录，不当作端到端成功。
